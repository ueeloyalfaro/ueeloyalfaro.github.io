# Unidad Educativa Fiscal Eloy Alfaro

Sitio institucional estático construido con HTML, CSS y JavaScript.

- Página inicial: `index.html` (en la raíz del proyecto).
- Secciones: Institución, Oferta Educativa, Vida Estudiantil, Noticias y Contacto.
- Recursos e imágenes: carpeta `assets/`.

## Abrir en local

Abre `index.html` en un navegador. Para publicar como GitHub Pages, usa la rama `main` y la carpeta `/(root)`.

Antes de publicar, confirma que la institución autoriza difundir nombres y fotografías de estudiantes. GitHub Pages es público en Internet.
